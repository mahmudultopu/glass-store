# SHADEO: Shopify eyewear store kit

Everything you need to launch **SHADEO**, a bold and modern sunglasses and eyeglasses store for Bangladesh (BDT, Cash on Delivery, bKash/Nagad), built on Shopify's free **Dawn** theme.

Inspired by the best Shopify eyewear stores (Quay, DIFF Eyewear, Pit Viper, Goodr). All design, code and copy are original.

## Build order

1. **Day 1:** Read `08-BRAND-GUIDE.md`, get the logo made, and create the Shopify store (Settings: BDT, Dhaka time zone).
2. **Day 1:** Follow `01-THEME-SETUP.md`, steps 1–6: install Dawn, upload the code, set colors and fonts.
3. **Day 2:** Set up collections, tags and metafields (`04-…`), then add products using the copy in `03-…`.
4. **Day 2:** Create the `lens-upgrade` product (`01-THEME-SETUP.md`, step 10).
5. **Day 3:** Build the homepage and product page (`01-THEME-SETUP.md`, steps 7–9) and add your product and banner photos.
6. **Day 3:** Install apps (`02-…`), paste policies (`06-…`), set up emails (`05-…`) and SEO (`07-…`).
7. **Day 4:** Run the whole `10-LAUNCH-CHECKLIST.md`.
8. **Day 5 onward:** Start `11-30-DAY-MARKETING-PLAN.md`.
